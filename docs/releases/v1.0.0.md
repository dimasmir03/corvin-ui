# Corvin UI v1.0.0

Первый стабильный крупный релиз панели в актуальной линии версий. Это описание охватывает изменения после `v0.26.2-rc1`.

## Главное

- Панель получила серверно-ориентированную модель VPN: один `server_id` представляет одну возможную точку подключения, без публичной модели hops/цепочек.
- Новый provisioning больше не создаёт `jobs`/`job_batches`. Состояние и повторная доставка команды ведутся через `vpn_profiles` и `vpn_profile_nodes`; чтение legacy results сохранено для плавного перехода.
- Добавлено глобальное виртуальное подключение `auto` с режимами `pinned` и `automatic`. Явно выбранный приложением сервер не переопределяется.
- Добавлен Mobile API v1 с Telegram PKCE login, JWT access token, opaque rotating refresh token, reuse detection, mobile sessions/devices, подпиской, каталогом серверов, idempotent connect, operations и diagnostics.
- VPN credentials теперь могут быть device-specific; миграция снимает старое ограничение «один VPNClient на пользователя» и создаёт частичные unique indexes для legacy/device credentials.

## Панель и VPN

- Управление статусом подписки, тарифом, сроком действия и лимитом устройств.
- Явный пользовательский allow-list серверов и протоколов. Пока правил нет, сохраняется совместимый режим доступа ко всем подходящим включённым серверам.
- Отображение устройств, device-specific клиентов, профилей, фактических серверных подключений и готовых config links.
- Настройка публичного endpoint каждого сервера: host, port, location, security, network, SNI, path и flow.
- Автоматический выбор сервера учитывает доступ пользователя, состояние агента/Xray, online count и свежесть snapshot.
- Backend-команды `enable_client`, `disable_client` и `delete_client`; для фактического исполнения требуется совместимый `vpnconsumer`.
- Повторная публикация незавершённых provisioning-команд без отдельной jobs-системы.

## Mobile API `/api/mobile/v1`

- `POST /auth/telegram/start`, `GET /auth/telegram/status`, `POST /auth/telegram/exchange`.
- `POST /auth/refresh` с обязательной rotation и блокировкой session при reuse.
- `POST /auth/logout`.
- `GET /bootstrap`, `/servers`, `/subscription`, `/devices`.
- `DELETE /devices/{device_id}` с отзывом сессий и постановкой удаления remote credentials.
- `POST /vpn/connect` с `Idempotency-Key`, ответом `200` либо `202`.
- `GET /operations/{operation_id}`.
- `GET /vpn/diagnostics` и публичный быстрый `GET /connectivity-check` (`204`).
- Единый error envelope и rate limits для чувствительных ручек.
- Каталог не раскрывает public host, внутреннюю топологию, UUID/password или готовые конфиги.

## Серверы, мониторинг и Telegram

- Реестр обнаруженных/зарегистрированных серверов, snapshot history и managed inbound metadata.
- Состояния online/stale/offline/lost/abandoned, Xray availability, traffic, clients и online count.
- Ручной snapshot refresh и архивирование устаревших discovered nodes.
- Встроенный Telegram-бот: регистрация, VPN flow, `/link`, инструкции, поддержка/фото, admin-команды и уведомления.
- Telegram `/start login_<token>` подтверждает одноразовый Mobile login.
- Унифицированное структурированное логирование и request IDs; секреты исключены из моделей/API/log payloads.

## Инфраструктура и безопасность

- PostgreSQL вместо старого SQLite runtime, MinIO для вложений и RabbitMQ TLS (`amqps`).
- Конфигурация вынесена в `/etc/corvin-ui/corvin-ui.env`; `corvin-ui init` генерирует секреты один раз.
- Панель по умолчанию слушает loopback; публичный bind запрещён при `AUTH_MODE=none`.
- `/health` и `/ready` для systemd/deploy checks.
- `corvin-ui compose`, `doctor`, `env`, `settings`, `upgrade`.
- `corvin-ui upgrade VERSION` проверяет SHA-256, делает PostgreSQL backup, ставит release, запускает миграции, проверяет readiness и откатывает бинарник при неудаче.
- GitHub Actions: CI с vet/race tests/build, release gate, checksums и ручной production deploy через Tailscale + SSH.

## Миграции БД

При старте автоматически создаются/обновляются:

- `server_registry`, server inbound/snapshot tables;
- `endpoint_groups`, `vpn_clients`, `vpn_profiles`, `vpn_profile_nodes`;
- `user_subscriptions`, `user_server_access`, `vpn_routing_settings`;
- `mobile_devices`, `mobile_login_sessions`, `mobile_sessions`, used refresh token history;
- mobile operations и idempotency records;
- audit и legacy compatibility tables.

Перед обновлением `corvin-ui upgrade` сохраняет SQL backup в `/var/backups/corvin-ui/`.

## Требуемая настройка после обновления

Mobile API добавляется в env в выключенном состоянии. Для включения задайте:

```dotenv
MOBILE_API_ENABLED=true
MOBILE_TELEGRAM_BOT_USERNAME=your_bot
MOBILE_PUBLIC_BASE_URL=https://your-mobile-api.example.com
```

`MOBILE_JWT_SECRET` генерируется upgrade/install wrapper автоматически. Проверьте публичный HTTPS reverse proxy только для `/api/mobile/v1`; admin panel может оставаться доступной исключительно через SSH/Tailscale tunnel.

Для remote enable/disable/delete обновите `vpnconsumer` по инструкции `docs/vpnconsumer-v1-prompt.md`.
